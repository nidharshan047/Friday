# Friday — personal AI assistant

This repository is for the Friday mobile-first personal AI assistant.

## Planned stack
- Expo / React Native mobile app
- TypeScript API server
- Supabase for persistence
- Optional ElevenLabs voice integration

## Status
This README is only a project overview; it does not indicate that the app source or Android build is complete.

## Security
Keep API keys on the server and never commit real credentials.
